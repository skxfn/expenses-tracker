# Трансфер: чат по дизайну «Траты»

Ты продолжаешь проект личного iOS-трекера расходов «Траты». Бэкенд, временный UI и сборка готовы. Задача этого чата — **вместе с пользователем выбрать и внедрить дизайн**. Пользователь ничего не утвердил: сначала обсуждение и варианты, код — только после явного «да».

## Что прочитать первым
- `AGENTS.md` — решения и ловушки проекта (обязательно).
- `design/references.md` — разбор референсов; `design/references.json` — то же машиночитаемо; `design/gallery.html` — галерея со скриншотами (открывать в обычном браузере: во встроенном превью CSP режет внешние картинки; либо `.claude/launch.json` → сервер `design-gallery` на :8765).
- `README.md` — сборка и установка.

## Проект в двух словах
- SwiftUI, iOS 17+ (deployment target), Swift 6, `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor`. Только iPhone, портрет. Сборка — Xcode 26.6 (iOS 26.5 SDK), поэтому системные компоненты на iOS 26+ получают Liquid Glass автоматически.
- **Устройство пользователя — iOS 27.** Симулятора iOS 27 нет (только iOS 26.5) — проверять на нём, оговаривая разницу.
- Установка — неподписанный `.ipa` через SideStore (бесплатный Apple ID). Нельзя: виджеты/расширения (лимит App ID), push, iCloud, App Groups и прочие платные entitlements.
- Репозиторий: https://github.com/skxfn/expenses-tracker (публичный).

## Архитектура — что можно менять
- `Packages/ExpenseCore` — модели SwiftData, `ExpenseStore` (все изменения данных), статистика, бэкап, деньги, каталоги. **Не трогать без нужды**; если нужно — минимально и с тестом (`cd Packages/ExpenseCore; swift test`, сейчас 106 тестов).
- `App/Features/*/…Model.swift` (`ExpenseFormModel`, `StatisticsModel`, `CategoryFormModel`, `BackupModel`, `ExpensesListContent`) — логика представления, при смене дизайна остаётся.
- **Переписываются View**: `ContentView.swift`, `Features/Expenses/ExpensesView.swift`, `Features/ExpenseForm/{ExpenseFormView,CategoryGridPicker}.swift`, `Features/Statistics/{StatisticsView,StatisticsCharts}.swift`, `Features/Categories/*View*.swift`, `Features/Settings/*View.swift`, `App/Shared/*`. Сейчас там системные List/Form — это временная заглушка.
- Иконки категорий — SF Symbols из `CategoryIconCatalog` (только доступные в iOS 17), цвета — `CategoryPalette` (контраст ≥ 3:1 на светлом и тёмном). Иконки приложения нет — `AppIcon.appiconset` пустой.

## Какие данные есть для экрана статистики
`StatisticsModel` (поверх `StatisticsEngine`) отдаёт для выбранного периода (день/неделя/месяц/год, листание ‹ ›) и фильтра по категории:
- `summary`: итог, количество, средняя в день, итог прошлого периода, изменение в % (к прошлому периоду **целиком** — в начале месяца всегда большой минус; это вопрос и к UX, и к движку: можно сравнивать «за те же дни»);
- `categoryRows`: категория, сумма, доля 0…1 (тап → фильтр);
- `timeSeries`: столбцы с нулями (час/день/месяц по периоду);
- `cumulative`: накопительные кривые «текущий vs прошлый» по номеру дня;
- `weekdays`: средние по дням недели;
- `topExpenses`: крупнейшие траты.

## Референсы (Mobbin недоступен: MCP требует платный план — не пытаться)
Источник — скриншоты App Store. Направления:
- **Добавление расхода:** A — калькулятор на весь экран (Dime, Monefy); B — сетка категорий + компактная клавиатура (Money+, EZ Money Tracker); C — сумма + лента чипов категорий (Daily Cost, Toshl); D — сначала категория (Monefy, CoinKeeper). Рекомендация исследователя: показать B и C.
- **Статистика:** S1 — donut + список категорий; S2 — бары по времени + переключатель периода + фраза-сравнение (Dime, Apple Card/Wallet); S3 — накопительная линия и темп; S4 — тепловая карта + карточки-инсайты. Рекомендация: S2 + S1 в одном прокручиваемом экране, S3/S4 — карточками вторым кругом.
- Мелкие находки (в `references.md`): ввод «Pre-dotted» (599 → 5,99 — ложится на `amountMinor`), кнопка «Ещё» рядом с «Готово», частые категории первыми, чипы быстрых сумм, сравнение на ту же дату прошлого месяца, режим скрытия сумм.
- Dime — open-source на SwiftUI, но **GPL-3.0: код не копировать**, только смотреть идеи.

## Вопросы, которые стоит обсудить с пользователем
1. Какие направления нравятся (буквы A–D и S1–S4), можно смешивать.
2. Ввод суммы: системная `.decimalPad` (сейчас) или своя клавиатура; режим «Pre-dotted»?
3. Категория обязательна или нет (сейчас необязательна, без выбора по умолчанию); запоминать последнюю/частые?
4. Главный экран: лента по дням (сейчас) или календарь; где кнопка добавления.
5. Стиль: акцентный цвет, светлая/тёмная, насколько опираться на Liquid Glass (iOS 26+) с запасным видом для iOS 17.
6. Иконка приложения.
7. Сравнение с прошлым периодом — «целиком» или «за те же дни» (второе требует правки движка).

## Как работать
- Сначала варианты и мокапы (можно HTML-мокапы/артефакты или SwiftUI `#Preview`), выбор — за пользователем. Код экранов — после утверждения.
- Проверка в симуляторе: `xcodebuild -project Expenses.xcodeproj -scheme Expenses -destination 'platform=iOS Simulator,id=<udid>' -derivedDataPath <scratchpad>`; есть симулятор `Expenses-UI-iPhone17` (UDID `2DB282C3-13E7-4A86-A065-23F7DF1BC6D0`). В DEBUG аргументы запуска: `-demoData YES` (демо-траты в пустую базу), `-debugTab statistics|settings`. Скриншоты — `xcrun simctl io <udid> screenshot`, в scratchpad, не в репо. Для тапов через панель симулятора пользователь должен дать доступ («Let Claude use it»).
- Сборка `.ipa`: `./scripts/build_ipa.sh` (сам поднимает версию). Только API iOS 17.0 или с `#available`.
- Коммиты — логическими блоками, на русском; журнал — `AGENTS.md`.
