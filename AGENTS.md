# Журнал проекта «Траты»

## Решения
- Bundle ID `com.skxfn.expenses` постоянный: смена = новое приложение в SideStore и потеря данных.
- Проект генерируется XcodeGen из `project.yml`, `Expenses.xcodeproj` закоммичен (чистый клон собирается без xcodegen). После правки `project.yml` — `xcodegen generate`. `App/` — synced folder: новые файлы в проект добавлять не нужно.
- Логика (модели, хранилище, статистика, экспорт) — в пакете `Packages/ExpenseCore`, тесты гоняются на маке: `cd Packages/ExpenseCore; swift test`. UI — в `App/`.
- Сумма хранится как `Int64` в сотых долях валюты (`amountMinor`), валюта одна на приложение. Без Double для денег.
- Модели вложены в `SchemaV1` (VersionedSchema) + `ExpenseMigrationPlan`: любое изменение моделей — через новую версию схемы, иначе данные пользователя потеряются при обновлении.
- Все изменения данных — через `ExpenseStore` (валидация + save), `@Query` — только чтение.
- При запуске `CurrencySettings.ensureCurrencyCode` вызывается до показа сумм: иначе смена региона iOS молча поменяет валюту всех записей.
- Статистика считается по `ExpenseRecord` (value type); интервалы полуоткрытые `[start, end)`. Средняя/кривая текущего периода — по сегодня включительно.
- Формат бэкапа версионируется `formatVersion` (сейчас 1); при несовместимой смене поднять `BackupFormat.currentVersion` и сохранить чтение старых версий.
- Версия — только в `Config/Version.xcconfig`; `scripts/build_ipa.sh` поднимает её сам, в CI — `--no-bump`. Тег релиза строго `v<MARKETING_VERSION>`, иначе Action падает.
- Репо — публичный `skxfn/expenses-tracker` (`DEFAULT_REPO` в `scripts/update_source.py`, в Actions — `$GITHUB_REPOSITORY`). Должен оставаться публичным — иначе SideStore не скачает релизы.
- UI: тонкие View + `@Observable` модели рядом (`ExpenseFormModel`, `StatisticsModel`, `BackupModel`…). При внедрении дизайна переписываются только View и `App/Shared`, модели остаются.
- Дизайн утверждён 2026-10-09: финал — страница холста «Образцы — экраны», дальше только тёмная тема и тексты поверх неё. Текущий UI в `App/` временный. Референсы — `design/` (`gallery.html` открывать в обычном браузере), Mobbin MCP требует платный план. Dime (open-source) под GPL-3.0 — код не копировать.
- Дизайн-система «Образцы» задокументирована в `DESIGN.md` (+ `.impeccable/design.json`) — источник истины для реализации UI; пользователь просил её сохранить. Тёмная тема — страница холста «Тёмная тема», значения — `design.json` → `extensions.darkTheme`: раскладка как в светлой, меняются только цвета. Макеты Swatch-Add и Sheet-*/Ultra-* на холсте устарели.
- Дизайн (скилл impeccable) — холст https://claude.ai/artifact/Wkh9EydSQCAbkH1tYXHPDB, страницы «Итерация 2», «План интерфейса», «Итерация 1». Выбрано направление «Образцы»: бумага #F3F0EA + графит #221D18, цифры — Unbounded, UI — SF, цвет несут только данные. Продуктовый контекст для скилла — `PRODUCT.md`.
- Палитра категорий — «Гуашь» (12 цветов одной громкости; значения — доска «Палитра «Гуашь» и иконки» на холсте) вместо `CategoryPalette`: большие площади только тинтами, насыщенный — мелкими элементами. Старые hex в данных и бэкапах переводить по таблице «старый → новый» (это замена значений, не новая схема).
- Иконки категорий — MingCute Fill (Apache 2.0) вместо SF Symbols; в данных лежат имена SF Symbols — нужна таблица соответствий при запуске и в импортёре.
- Иконки категорий в данных — имена MingCute = имена ассетов (`CategoryIconCatalog`, 77 шт.; 14 имён вне `migration.json` подобраны сверкой контуров макета `Obr-Category` с Iconify). Цвет категории — только основной тон `GouacheTone` (у подкатегории = тон родителя). Ступень оттенка подкатегории — позиция по `sortOrder` среди сестёр (архивные держат место), `index % 5`; перенос → в конец.
- Резервная копия — формат 2; формат 1 переводится при чтении (`ImportReport.isFromPreviousFormat` → строка `import.v1`). Ошибки чтения — `BackupError.UnreadableReason`, `rawValue` → id `error.backup.detail.<rawValue>`.
- Deployment target — iOS 26: Liquid Glass на всём «хроме», без `#available` и запасного вида.
- Решения по экранам: тап по иконке категории на обзоре главного → статистика категории (там — анимация раскрытия); быстрые суммы фиксированные 5/10/20/50/100 и прибавляются к введённой; своя калькуляторная клавиатура отвергнута — системная цифровая.
- Свой период — на главной и в статистике (пятый пункт сегмента): ‹ › сдвигают на длину диапазона (5–7 окт → 2–4 окт), сравнение — с предыдущим диапазоном той же длины. В виде «Стопка полос» отдельного списка групп нет: полосы сами список (имя, %, сумма).
- Категории двухуровневые: группы (до 15, у каждой свой цвет «Гуаши») + подкатегории без ограничения, цвет — оттенок группы (не выбирается). Трату можно записать и в группу, и в подкатегорию («без подкатегории» в статистике). Это изменение модели → новая версия схемы (`SchemaV2`, родитель у категории) и новая версия формата бэкапа с чтением v1.
- Визуализация категорий: обзор на главном переключается в настройках — «Плитки» (по умолчанию) или «Кольцо»; в статистике раздел категорий переключается между всеми четырьмя видами («Плитки», «Полосы», «Солнце», «Кольцо»). Веер отложен — плохо масштабируется. Макеты — страница холста «Категории: варианты».
- Подписи на цветах «Гуаши» — графитом или светлым текстом: белый на основных оттенках ≈ 3,4:1. Группы < 3% (если их ≥ 2) сворачиваются в «ещё N»; в кругах порядок групп по оттенку, в списках — по сумме.
- Решения по текстам (2026-10-09): «трата»; «категория → подкатегория» (слово «группа» в интерфейсе не используется); виды диаграмм — «Плитки · Полосы · Солнце · Кольцо» (вместо «Карта образцов · Стопка полос · Солнце · Просто круг»); обращение безличное; тон статистики нейтральный («Потрачено за 8 дней»); сравнение — «чем в прошлом месяце / на прошлой неделе / вчера / в прошлом году», для своего периода «чем за 2–4 окт»; «Резервная копия» вместо «бэкап».
- Фундамент UI (`App/Shared/Theme`, `App/Shared/Components`): токены — `python3 scripts/gen_tokens.py` (`--check`) → `Tokens.generated.swift` (руками не править), hex-литералы только в `Theme/`; иконки — `python3 scripts/import_mingcute.py <распакованный npm mingcute_icon/package>` (2.9.72), имена из `CategoryIconCatalog`; Unbounded 1.701 (`Unbounded-Medium`/`-SemiBold`, `tnum` есть) — `UnboundedFont.register()` в `ExpensesApp.init`. DEBUG-витрина: `-debugShowcase YES|tokens|tones|components|glass|fonts|tabBarCustom|feed|addSheet`.
- Таб-бар — свой (`GlassEffectContainer` в `safeAreaInset(edge: .bottom)` поверх `TabView` с `.toolbarVisibility(.hidden, for: .tabBar)`): системная капсула iOS 26 центрируется, и «+» на неё наезжает. Нативный `Tab(role: .search)` как «+» проверен (2026-10-12) и отвергнут: при перехвате выбора мигает пустая вкладка под шитом, нет prominent-«+» и зума. Выделение — системная стеклянная линза (`.glassEffect(.regular.interactive())` в общем `GlassEffectContainer`): касание поднимает, палец ведёт, пружина `Motion.morph` — по образцу Telegram (у них приватный `_UILiquidLensView`, публичного аналога нет). Календарь: линза у выбранного дня и переезжает к нему (решение владельца 2026-10-12), «сегодня» без выбора — подчёркивание числа.
- Навигация: `AppRouter` (вкладка, общий шит `AppSheet`, `StatisticsFocus`) и `PendingDeletion` (удаление с отменой 4 с) — в окружении из `ContentView`; шит траты — только `router.presentAdd(date:)`/`presentEdit(expenseID:)` → `ExpenseSheet(mode:)`. Строка траты везде — `ExpenseRow(ExpenseRowData(expense))`. Локаль форматтеров — `Locale.app` (по `AppLanguage`: ru_RU или en_US), символ валюты — `MoneyFormatter.currencySymbol`.
- Пакет для внедрения дизайна: начинать с `design/INTEGRATION.md` (старшинство источников, этапы, открытые вопросы владельцу), картинки экранов — `design/mockups/{light,dark}/`, миграция цветов, иконок и имён категорий — `design/migration.json`. Картинки выгружены из HTML-макетов холста; при правке макетов перегенерировать.
- Финальные тексты интерфейса — `design/copy.json`: у каждой строки поле `final`; там же голос, глоссарий и решения D1–D8. Строки брать оттуда, не придумывать заново. Отсмотр был на https://claude.ai/artifact/AAqAMSDzGeJQ7Kki6C2jbM (выбор пользователя — в базе артефакта, документ `review/state`).
- Тексты в коде: `design/copy.json` → `python3 scripts/gen_strings.py` → `App/Resources/Localizable.xcstrings` (руками не править; скрипт аргументов не разбирает — любой запуск, даже с `--help`, перезаписывает каталог), проверка — `python3 scripts/check_copy.py`. Ключ = id (исключения и разбиения вариантов — таблица SPEC в `gen_strings.py`). Строки с `%lld`/подстановками — только через `L10n.format`/`L10n.attributed` (локаль `L10n.locale`): Foundation выбирает форму числа по локали форматирования. Выделение во фразах — `**…**` в каталоге (список `EMPHASIZED`), стилизация через `runs`.
- Знак валюты (решение владельца 2026-10-10): вместо «Br» везде новый официальный знак белорусского рубля — «Б» с чертой, U+20C5 (в Unicode только с 19.0, 2027; в шрифтах iOS его нет). Глиф — `design/assets/BYNSign.ttf` из `byn-sign.svg`, как подключать — `design/INTEGRATION.md` §3.3.1. Макеты, DESIGN.md и INTEGRATION.md уже переведены; в коде, `copy.json` и `gen_strings.py` — задача внедрения (менять одним коммитом). Вне приложения — `BYN`. В настройках выбор «Обозначение»: знак (по умолчанию) | `BYN` (`currencySymbolStyle`, только для валюты BYN) — спецификация в том же §3.3.1.
- Иконка приложения (решение владельца 2026-10-10): «Чек-выкраска» — оторванный бумажный чек с дыркой и рваным краем на графитовом фоне, внутри образцы категорий «Гуаши». Макет — страница холста «Иконка приложения», артборд Icon-6; слои и режимы для Icon Composer — `design/app-icon/`.
- Английская версия текстов — `design/copy.en.json` (поле `final`, решения E1–E10 приняты рекомендованные, отсмотрена критиком; `copy.json` не трогать). Как переносить и что перевёрстать — `design/INTEGRATION.md` §5.5. Формат денег и дат для английского — свой en-US («1,412.60 ₅», «Oct 5–7»; ₅ = U+20C5), не из региона: английский с регионом Беларусь даёт «1 412,60». Язык — `AppLanguage` (по `Bundle.main.preferredLocalizations`); даты и слова — через `AppLanguage.current.dateFormatter` (`DateTextFormatter`), не `RussianDateFormatter`/`RussianWords` напрямую. Английские строки — таблицы `EN`/`EN_SPEC` в `gen_strings.py`; если английской фразе нужен свой ключ — добавлять его и в ru с тем же русским текстом. Знак BYN `MoneyFormatter` ставит после числа сам, не через ICU. Третий язык получит русский (исходный язык — ru).
- Экрана «Лицензии» нет (решение владельца 2026-10-12), но `MingCute-LICENSE.txt`, `OFL.txt`, `BYNSign-NOTICE.txt` в бандле обязательны (Apache 2.0, OFL) — код на них не ссылается, при чистке не удалять.
- Внедрение дизайна идёт в ветке `dev` (2026-10-09). Открытые вопросы `design/INTEGRATION.md` §8 владелец не решал — приняты рекомендации из §8 (п. 1–19) как есть; выбор держать в одном месте (константа/компонент), чтобы поменять одной правкой.
- Клетка календаря: копейки до 100 Br (по `copy.json` → `cal.cell.amount`, тексты главнее INTEGRATION §5.2); константы порогов — `MoneyFormatter`, статистики — `StatsThresholds`.
- Время — 24-часовое в обеих версиях («14:00», и в английской тоже), формат фиксированный, не из настроек телефона (решение владельца 2026-10-12). Ответы на вопросы разработчика с новыми строками — `design/answers-2026-10-12.md` — перенесены в `copy.json`/`copy.en.json`. Время — `DateTextFormatter.hour` (`HH:mm`), ось — `hourOfDay`.
- Пороги (§8 п. 11), заданы при внедрении: «примерно как» — |разница| < 1 %; «почти поровну» будни/выходные — ±10 %; «Темп» — идущий период, прошло ≥ 3 дней и ≥ 3 траты; «Привычки» — траты в ≥ 7 разных днях; шкала heat — квартили дневных сумм года, округлённые до «круглых» чисел, одна для календаря и карты; прогноз — 2 значащие цифры.
- `stats.fewData` (решение владельца 2026-10-10): русская строка остаётся как утверждена («через пару дней», «после двух недель»), к порогам `StatsThresholds` не приводится; английская называет пороги точно.
- Пожелания пользователя к дизайну: добавление как в Spendly, главный как в Monefy (кольцо с иконками + лента), редактор категории как в EZ Money Tracker, красивый календарь отдельной вкладкой, статистика S1–S4 все, свой произвольный период и на главном, иконки категорий — из библиотек (не эмодзи).
- ИИ-запись трат (текст, фото чека, голос; решение владельца 2026-10-10): клиент Anthropic Messages API по base URL + ключу из настроек (сервер — прокси, доступный из РБ без VPN), без SDK; ключ только в Keychain, в репо не попадает. ТЗ для разработчика — https://claude.ai/code/artifact/789148a3-f11d-45dc-991d-dbcc99382a9e. Если прокси отпадёт — запасные варианты, проверенные на доступность из РБ: DeepSeek `deepseek-flash`, Qwen-VL, GLM-4.6V (OpenAI-формат); OpenRouter, GigaChat, Mistral не годятся.

- Траты на экранах читают модели, не `@Query`: `HomeModel` (от начала сравнения D5 до конца периода + последняя трата), `CalendarModel` (год + выбранный день), `StatisticsModel` (`appear`/`dataDidChange`); подписка на сохранение — только `onDataSaved` (`App/Features/Shell/DataSaveObserver.swift`: синхронно, только главный контекст). `.receive(on: .main)` даёт кадр с удалённой строкой и старыми итогами, счётчик ревизий через `onChange` — промах прокрутки к новой строке. Перевод в `ExpenseRecord` в `body` на большой базе даёт зависания до 1 с.
- Сравнение: `StatsTrend.incomparable` (в прошлом периоде траты были, но не к этому дню) — фразы сравнения нет ни на экране, ни в VoiceOver; `SummaryTexts.comparison` → `Comparison?`.
- Экраны: период — `App/Features/Period` (у каждого экрана свой `PeriodSelection`; «Свой» без диапазона открывает шит; готовые периоды применяются сразу, «Прошлый месяц» = вид «Месяц»). Оболочка: корни вкладок без навигационной панели, пуши — `AppRoute` + `NavigationLink(value:)`, таб-бар прячется при пуше, зум шита только из «+» (`.add(date: nil)`).
- Календарь: месяц без шита (‹ › и свайп), раскладка — `MonthGrid` в Core, пороги шкалы — `MoneyFormatter.Style.wholeUnits`; будущие дни без трат не выбираются. Траты календарь выбирает сам (`CalendarModel`: год показанного месяца + выбранный день, обновление по `ModelContext.didSave`), не `@Query`. Смена дня — `.onCalendarDayChange` (`App/Features/Period/CalendarDayChange.swift`). Шапка периода: если заголовок не влезает при `minimumScaleFactor` 0,5, управление уходит строкой ниже (`PeriodHeaderRow`); `-debugPeriod pastYear`. Линза «сегодня» — `.clear`, подкрашенный цветом клетки, с тенью снаружи (иначе на светлых клетках не видна).
- Запись траты: логика — Core `Entry/` (`AmountInput`, `EntryDate`, `ExpenseDraft`, `EntryBatch`, `SwatchRow`); ошибки Core в UI — только через `UserFacingError.message(for:)` (тексты copy.json).
- DEBUG-аргументы: `-demoData YES`, `-debugTab expenses|calendar|statistics`, `-debugPeriod YES|day|week|year|range|past|pastYear|sheet`, `-debugRoute settings`, `-debugToast YES`, `-debugAdd YES`, `-debugSheet add|edit|filled`, `-debugSubsheet picker|date|batch`, `-debugScreen settings|category|categories`, `-currencyCode BYN`, `-debugShowcase …`.
- Визуализации категорий — `App/Features/CategoryViz/`; данные — `CategoryVizData` + `CategoryCatalogSnapshot` (Core, без SwiftData). Главная: `CategoryTilesView(homeData:…)` / `HomeCategoryRing`; статистика: `StatsCategorySection`. Размеры с макетов — `VizMetrics`/`RingMetrics`. Переключатель «Категории / Подкатегории» — только в раскрытых «Плитках» (на макетах его нет; толкование). Витрина: `-debugShowcase viz` + `-vizView home|homeRing|tiles|strips|sun|ring`, `-vizData demo|many|uncategorized|few|one|empty|dominant|dominantPair`, `-vizExpand YES`.
- Иконка приложения — `App/Resources/AppIcon.icon` (Icon Composer: слои из `design/app-icon/`, режимы по INTEGRATION §3.8). `icon.json` собран вручную по образцу реальных `.icon` и проверен рендером `ictool` (`Icon Composer.app/Contents/Executables/ictool <icon> --export-image --platform iOS --rendition Default|Dark|TintedLight|TintedDark|ClearLight|ClearDark …`); открывается и правится в Icon Composer. Имена групп — латиницей (кириллица в Assets.car становится «_»). Картинка для SideStore — `Config/AppIcon-512.png` (рендер Default), её берёт `update_source.py`.
- Знак рубля U+20C5: шрифт `BYNSign.ttf` подставляется через cascadeList в `typeStyle` (`CurrencySignFont`); настройка «Обозначение» — `SettingsKeys.currencySymbolStyle` (`CurrencySymbolStyle` sign|code), читает только `MoneyFormatter` (`symbolStyle`), строка в настройках только для BYN. Скриншоты с рублём: `-currencyCode BYN`, кодом — `-currencySymbolStyle code`, витрина — `-debugShowcase currencySign`.
- Главная — `App/Features/Home` (`-debugHome ring,range,empty,scrolled,saved,day,week,year,past`); подсветка новой траты — `AppRouter.savedExpenseID`. Статистика — `App/Features/Statistics` (`-statsPeriod day|yesterday|week|year|range|past|pastYear`, `-statsExpand YES|<имя>`, `-statsScroll summary|categories|days|pace|habits|year|top`, `-statsFocus <имя>`, `-statsCategoryView tiles|strips|sun|ring`). Раскрытая категория фильтрует и сводку; «Крупнейшие траты» — 3 строки; карта года — у всех периодов, кроме «Дня».
## Ловушки
- Xcode 26: без установленной iOS-платформы (`xcodebuild -downloadPlatform iOS`) сборка по схеме падает «iOS 26.5 is not installed»; `-target Expenses -sdk iphoneos` при этом собирается.
- SwiftData: `transaction {}` при ошибке не откатывает — нужен явный `rollback()`, после него заново выбрать модели (старые ссылки падают «model instance was invalidated»).
- Даты в бэкапе — через `BackupFormat` (ISO 8601 с округлением до мс). `.iso8601`/наивный `ISO8601FormatStyle` теряют доли секунды и сдвигают дату на 1 мс за цикл.
- `DateInterval.contains` включает `end` — для периодов не использовать.
- Контейнеры (и в тестах) — только через `ModelContainerFactory` (`make(inMemory:)`, `make(storeURL:)`): там лок — параллельное открытие хранилищ одной схемы роняет Core Data (`_generateTriggerSQL`); контейнер на `SchemaV1` при typealias на V2 падает «Failed to cast model … to Expense».
- Тестовое хранилище V1 писать через Core Data (`NSManagedObjectModel.makeManagedObjectModel(for: SchemaV1.models)` + `newBackgroundContext`), не классами `SchemaV1`: рядом с V2 SwiftData путает сущности и падает на `save`.
- SideStore сверяет sha256, размер и version/build `.ipa` с `source.json`: ассет релиза не перезаливать без `update_source.py`.
- Без подписи entitlements в `.app` не встраиваются — `build_ipa.sh` проверяет `CODE_SIGN_ENTITLEMENTS` проекта. `-showBuildSettings` — только с `-target` (со схемой без iOS-платформы падает).
- Симулятор: `xcodebuild -scheme Expenses -destination 'platform=iOS Simulator,id=<udid>' -derivedDataPath <scratch>`; сборка через `-target … CODE_SIGNING_ALLOWED=NO` ставится, но `simctl launch` на ней зависает. В DEBUG: `-demoData YES` (демо-траты в пустую базу), `-debugTab statistics|settings`.
- `Text("ключ.\(x)")` ищет ключ `ключ.%@`: ключ из переменной — только `Text(LocalizedStringKey(key))`. `Text("ключ")` разбирает Markdown — других знаков Markdown в строках каталога быть не должно.
- `List(.plain)`: закреплённые заголовки секций игнорируют верхние `safeAreaInset`/`safeAreaBar` — шапку ставить над `List` в `VStack`, заголовку секции давать фон `Theme.surface`.
- Клавиатурная панель iOS 26: `ToolbarItemGroup(placement: .keyboard)` даёт одну общую капсулу; отдельные клавиши — один `ToolbarItem` со своим рядом и `.sharedBackgroundVisibility(.hidden)`.
- В Unbounded нет U+202F: в суммах Unbounded только U+00A0 (иначе подставится запасной шрифт).
- `.fileExporter` сам дописывает `.json` по типу — `defaultFilename` передавать без расширения.
- Не читать свойства удалённой SwiftData-модели: sheet-маршруты и модели форм копируют `id`/флаги при открытии.
- Сравнение по D5 («к той же дате») — `StatisticsEngine.comparisonInterval`; `StatsSummary.previousTotalMinor` — сумма «к той же дате», а не всего прошлого периода.
- Числа и даты для UI — только через `ExpenseCore/Formatting/` и `MoneyFormatter.Style`: системный `ru` даёт «35 %», «окт.», «г.» с U+202F. Символ BYN: ICU даёт «Br» только в `ru_BY` (в `ru_RU` — «BYN», narrow — «р.»), замена — `MoneyFormatter.symbolOverrides` (по решению 2026-10-10 — на U+20C5, не «Br»). Локаль форматтеров в App — только `Locale.app` (по языку интерфейса, регион устройства не влияет), не `.autoupdatingCurrent`.
- iOS 26: склейка `Text + Text` устарела — выделение во фразе делать интерполяцией; `swipeActions` работают только в `List` (свайпы в `ScrollView` — с iOS 27), ленту делать на `List`.
- Swift Charts на iOS 17: свой тип `AxisContent` объявить нельзя — общие оси через функцию `some AxisContent`.
- Устройство пользователя — iOS 27. SideStore нужен ≥ 0.7.0-alpha (0.6.4 и старше не логинятся после изменений Apple в сент. 2026). На iOS 27 шорткат «Refresh All Apps» может падать с ADI -45061 — обход: SideStore → Settings → User Customizations → Reset adi.db (SideStore#1596).
- SideStore 0.7.0-alpha делает имя App ID из `CFBundleDisplayName` как есть, а Apple отклоняет кириллицу («invalid value … for the parameter 'appIdName'») — базовое имя в `project.yml` только латиницей (`Expenses`), «Траты» — из `InfoPlist.xcstrings` (ru).
- SideStore может дописать к Bundle ID `.<TeamID>`: ничего не хардкодить по bundle ID; смена Apple ID = новое пустое приложение (данные — только через бэкап).
- Apple Foundation Models не знает русского (и в iOS 27) — разбирать трату на устройстве нечем. Vision OCR по-русски — только `.accurate` с `ru` первым в `recognitionLanguages`; русская речь — `DictationTranscriber`, не `SpeechTranscriber` (проверено на macOS 26). QR белорусского чека — только 24-символьный УИ без даты и суммы; позиции отдаёт лишь `ch.info-center.by` за reCAPTCHA, API нет.
- `ScrollPosition.scrollTo` в `onAppear` у `LazyVStack` промахивается — начальную позицию задавать в `State(initialValue: ScrollPosition(id:anchor:))`. У конца ленты `ScrollPosition(id:)` упирается в край без учёта нижнего `safeAreaInset`, а `viewID` остаётся запрошенным — верхнюю строку брать из `onScrollGeometryChange`, до конца докручивать `scrollTo(edge: .bottom)`.
- Системная «Назад» в iOS 26 — только стрелка в круге; капсулу «‹ Траты» из макета ею не получить.
- `period.range.meta` уже содержит «≈» — сумму давать `.phrase` от `Money.roundedToWholeUnits`, не `.approximate`.
- Быстрые суммы шита записи — свой ряд в `safeAreaBar` под «Сохранить», не `ToolbarItem(.keyboard)`: панель клавиатуры живёт в окне клавиатуры, её место между iOS 26.5 и 27 разное, и отступ «по замеру» на iOS 27 уводил весь шит вверх (2026-10-12). Шит записи: содержимое в `ScrollView` + `FillHeightLayout` (`frame(minHeight:)` в `ScrollView` промежутки не раздвигает), сумма и кнопки ограничены AX1.
- Симулятор под нагрузкой (load average сотни): `simctl launch` зависает — `shutdown`, `boot`, `bootstatus`. Ввод через MCP-симулятор (`text`) переключает его на аппаратную клавиатуру.
- `ViewThatFits` проверяет только сумму ширин ряда, а не что каждая подпись влезает в свою долю — для равных долей и единого кегля сегмента свой `Layout` (`SegmentRow`).
- `ViewThatFits` проверяет идеальную ширину — многострочный `Text` её не уменьшает; перенос имени по словам держится на скрытом «пробнике» с самым длинным словом (`CategoryViz`).
- scratchpad общий у параллельных агентов — скрипты и снимки только в своей подпапке.
- Знак U+20C5 рисуется только через `typeStyle` или `CurrencySignFont.font(_:in:)`; `.font(.x)`, алерты, заголовки навигации и меню дают квадрат — там только код BYN. Новый `MoneyFormatter` без `symbolStyle` игнорирует настройку — в экранах брать `\.moneyFormatter` из окружения. В `BYNSign.ttf` нет PostScript-имени — ссылаться по файлу.
- Swift Charts: Liquid Glass в аннотациях не рисуется — стеклянные подсказки через `chartOverlay` + `ChartProxy`; подпись оси у конца данных пропадает даже с `.extended` — делать аннотациями на невидимых `PointMark`.
- `listRowBackground` строки `List` не обновляется при смене состояния — подсветку рисовать фоном в содержимом строки.
- `git add` с несуществующим путём падает целиком и не добавляет ничего — проверять список путей. `timeout` на этом маке нет — `perl -e 'alarm N; exec @ARGV'`.
- Если `didMigrate` стадии V1→V2 бросит ошибку, SwiftData уже перевела базу на V2 и стадию не повторит — поэтому `LegacyCatalogMigration.apply` (идемпотентный) вызывается ещё и при каждом запуске (`AppLaunch`).
- Предел одной траты — `Money.maxAmountMinor` (99 999 999 999,99): проверяется в поле, `ExpenseStore` и импорте копии, иначе сумма трат переполнит `Int64` в итогах и приложение упадёт на запуске.
- `en` в knownRegions дописывает `postGenCommand` в `project.yml`: XcodeGen не видит каталоги строк внутри synced folder. Имя под иконкой — `App/Resources/InfoPlist.xcstrings`.
- Скриншоты на английском — `-AppleLanguages "(en)" -AppleLocale en_US`. Язык базовых категорий фиксируется при первом запуске — для другого языка переустановить приложение.
- `zIndex` меняет порядок чтения VoiceOver, `accessibilitySortPriority` его не исправляет — линзы и выступы рисовать отдельным слоем (`anchorPreference`).
- iOS 26: шит ниже `.large` «парит» с полями, высота детента ≠ экран минус safe area — свой детент подбирать замером.
- Экран запуска — `Config/Info.plist` (`UILaunchScreen → UIColorName = LaunchBackground`): вложенных ключей среди `INFOPLIST_KEY_*` нет; остальное Info.plist генерирует Xcode (`GENERATE_INFOPLIST_FILE`).
- Главное действие («+», «Сохранить», «Готово») красить `Theme.prominent` (графит 88 % / night-ink 92 %), не `Theme.ink`. Тост с действием (`GlassToast`) сам забирает фокус VoiceOver и держит таймер, пока фокус на нём; с VoiceOver отмена удаления — 10 с (пересчёт при смене VoiceOver). `PendingDeletion.pause(for:)`/`resume(for:)` — счётчик удержаний по id пометки, предел 60 с (`maxHold`).
- Новый симулятор стартует на английском: для русских снимков `simctl spawn <udid> defaults write -g AppleLanguages -array ru-RU en` и `AppleLocale ru_RU`.
- `@Query` + `onChange(of:)` не видит правку полей: массив состоит из тех же объектов.
- Swift Charts при многих столбиках собирает их для VoiceOver в безымянные диапазоны — свои подписи через `accessibilityChildren`. Шрифт фрагмента `AttributedString` брать из окружения самого `Text`: ограничение `dynamicTypeSize` ниже по дереву в контекст, прочитанный выше, не попадает.
- Синхронную работу на главном потоке (резервная копия) предварять паузой ≈ 50 мс, иначе индикатор не успеет отрисоваться.
- Под нагрузкой `simctl ui content_size` виснет — размер текста аргументом `-UIPreferredContentSizeCategoryName UICTContentSizeCategoryAccessibilityM|…L|…XL|…XXL|…XXXL` (AX1…AX5; `AccessibilityMedium` молча не работает), тема в UI-тесте — `XCUIDevice.shared.appearance` (под нагрузкой применяется только после `shutdown`/`boot`). `test-without-building` может запустить старый UI-тест — `simctl uninstall <bundle>.xctrunner`.
- Фоновый вид внутри `.accessibilityElement(children: .contain)` попадает к VoiceOver пустой кнопкой даже с `.accessibilityHidden` — линзы держать вне контейнера. `GlassEffectContainer` со `spacing` > 0: бар с `.interactive()` при касании слипается с соседним стеклом. Линзу анимировать по `selection`, не по вкладке под пальцем.
- DEBUG: `-debugSheet filled` при каждом запуске дописывает траты в базу; с `-debugSheet` панель быстрых сумм часто не появляется — её проверять через «+».
- Проверка доступности на симуляторе: дерево XCUITest показывает детей у скрытых и `.combine`/`.ignore` элементов — «лишние» элементы им не проверить, подсказки и действия не видны. Reduce Motion/Transparency: `simctl spawn <udid> defaults write com.apple.Accessibility ReduceMotionEnabled|EnhancedBackgroundContrastEnabled -bool YES` + перезапуск; Increase Contrast — `simctl ui <udid> increase_contrast enabled`.
- Перевод SwiftData-моделей в `ExpenseRecord` ≈ 6 мкс на трату, повторная выборка 20k ≈ 350 мс — в `body` не делать. Проверка миграции на настоящей базе 1.0: `git archive main Packages/ExpenseCore` → пакет-генератор V1. Exit-тесты Swift Testing (`#expect(processExitsWith:)`) работают в пакете — ими проверять краши.
